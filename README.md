# ☕ Cafe Sales Analysis using SQL

Welcome to the **Cafe Sales Analysis** project — a comprehensive SQL-based exploration of a retail café's sales dataset. This project showcases how structured queries can uncover valuable business insights, mimicking the workflow of real-world data analysts and BI professionals.

---

## 📋 Project Overview

This is a complete end-to-end SQL analysis of a retail café’s transaction data. With **over 149,000 records**, this project analyzes sales patterns across **time**, **store locations**, **product types**, and **customer behaviors**.

---

## 🧰 Tools & Technologies

- **Database**: MySQL  
- **IDE**: DBeaver  
- **Dataset Format**: CSV (Realistic café sales transactions)

---

## 🎯 Project Goal

To extract meaningful, actionable insights using SQL that address real-world business questions in the **Retail** and **F&B (Food & Beverage)** domains.

---

## 🗃️ Dataset Summary

| Feature            | Description                                     |
|--------------------|-------------------------------------------------|
| `transaction_id`   | Unique ID for each transaction                  |
| `transaction_date` | Date of the transaction                         |
| `transaction_time` | Time when the transaction occurred              |
| `transaction_qty`  | Quantity of items sold                          |
| `store_location`   | Store branch (e.g., Lower Manhattan)            |
| `product_category` | Main category (e.g., Coffee, Tea)               |
| `product_type`     | Subtype of product (e.g., Brewed Tea)           |
| `product_detail`   | Specific product (e.g., Spicy Chai Latte)       |
| `unit_price`       | Unit price of each product                      |

- 🧾 **Rows**: 149,116  
- 🧾 **Columns**: 11  
- 🚫 **Missing Values**: None

---

## 📈 Key Business Insights

- ☕ **Coffee** is the top-selling category by quantity.
- 🏆 **Lower Manhattan** consistently drives high revenue.
- 🕒 Peak hours are between **7 AM and 10 AM**.
- 🔁 **Gourmet Brewed Coffee** and **Spicy Chai Latte** are top customer favorites.
- 📅 **Weekends in February** show higher performance than weekdays.

---

## 💻 How to Run This Project

1. Import the `cafe_sales.csv` file into your MySQL database using DBeaver.
2. Run `queries.sql` to execute all SQL queries.
3. Explore the output directly in DBeaver or export it to Excel/CSV.
4. Modify filters (e.g., dates, locations) to customize the analysis.
